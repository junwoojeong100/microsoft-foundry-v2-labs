# 다음 학습과 자격증

[English](../../reference/learning-resources.md) | **한국어**

**2026-09-24 확인.**
이 워크숍은 현재 Microsoft Foundry 학습 중 agentic app 영역을 준비합니다. 모든 AI 자격증 주제를 다루지는 않습니다.

## 워크숍과 AI-103의 대응

| 워크숍 범위 | Lab/모듈 | AI-103 기술 영역 | AI-103 비중 |
|---|---|---|---|
| 프로젝트 설정, 모델 선택, 역할, quota/비용 경계, 근거, 정리 | Lab 00–02, 09, 11; 담당자 설정 | Azure AI 솔루션 계획 및 관리 | 25–30% |
| Prompt Agent, MAF agent/tool/MCP, workflow, Hosted agent, 평가, tracing, 운영 | Lab 03–05, 07–09; C 모듈 | 생성형 AI 및 agentic 솔루션 구현 | 30–35% |
| 생성형 prompting으로 구조화 JSON 답변 만들기(부분); speech는 다루지 않음 | Lab 02, 07 | 텍스트 분석 솔루션 구현 | 10–15% |
| Search와 Foundry IQ로 retrieval/grounding(부분); Content Understanding extraction은 설계만 | Lab 06; [전문 범위](../labs/extensions/specialist-scope.md) | 정보 추출 솔루션 구현 | 10–15% |
| 여기서 다루지 않음 | 전문 범위 참고 | Computer vision 솔루션 구현 | 10–15% |

Computer vision, speech, Content Understanding 서비스 실행은 이 에디션에서 다루지 않습니다.
설계 전용 경계는 [전문 범위](../labs/extensions/specialist-scope.md)를 보세요.

[AI-102](https://learn.microsoft.com/credentials/certifications/resources/study-guides/ai-102)는 2026-06-30에 retired되었습니다.
AI-103은 Azure AI Apps and Agents Developer Associate 인증을 위한 시험으로 2026-06-19에 AI-102를 대체했습니다
([공지](https://learn.microsoft.com/partner-center/announcements/2026-june)). 위 기술 비중은 AI-103 study guide(2026-04-16 기준 skills measured)에서 가져왔습니다.
