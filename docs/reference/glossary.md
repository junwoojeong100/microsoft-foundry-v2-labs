# 초보자를 위한 용어 사전

| 용어 | 한 줄 설명 |
|---|---|
| Tenant / 디렉터리 | 조직의 계정과 identity를 관리하는 경계 |
| Subscription / 구독 | Azure 자원·비용·관리의 단위 |
| Resource Group | 관련 Azure 자원을 묶는 관리 폴더 같은 단위 |
| Endpoint | 프로그램이 요청을 보내는 서비스 주소 |
| Deployment name | 배포된 모델을 실제로 호출할 때 사용하는 이름 |
| SDK | 서비스 호출을 쉽게 해 주는 프로그래밍 라이브러리 |
| CLI / 터미널 | 명령을 입력해 도구를 실행하는 방식 |
| 가상환경 / venv | 프로젝트별 Python 패키지를 분리한 공간 |
| `.env` | 프로그램이 읽을 설정값 파일; 이 랩에서는 비밀을 넣지 않음 |
| JSON / JSONL | 구조화된 데이터 / 한 줄에 JSON 객체 하나씩 저장한 형식 |
| Prompt / Instructions | 모델에게 주는 요청 / 에이전트가 따를 업무 지침 |
| Tool | 모델이 요청하고 프로그램이 실제 실행하는 함수·API |
| MCP | 모델/에이전트와 도구 서버 사이의 표준 프로토콜 |
| RAG | 관련 자료를 먼저 찾아 모델의 응답 근거로 제공하는 방식 |
| Grounding | 응답을 실제 근거에 연결하는 것 |
| Citation | 답변이 참조하는 원문 위치·문서 식별자 |
| Knowledge source/base | IQ의 검색 원본 / 원본들을 묶어 검색하는 단위 |
| Managed identity | Azure 런타임이 비밀번호 대신 사용하는 관리형 identity |
| OBO / delegated | 최종 사용자의 권한 맥락으로 다른 서비스에 접근하는 방식 |
| Trace / span | 요청의 처리 흐름 / 그 안의 작업 한 단계 |
| Evaluation / evaluator | 결과를 기준에 따라 평가하는 과정 / 평가 규칙·모델 |
| Dev / holdout | 개선·선택에 쓰는 사례 / 마지막 확인까지 쓰지 않는 사례 |
| Lineage / 계보 | 어떤 데이터·지침·모델·버전에서 결과가 나왔는지 연결한 이력 |
| Fixture | 검사기 동작을 보기 위해 미리 정한 데이터; 실제 LLM 결과가 아님 |
| GA / Preview | 일반 제공 / 별도 제한·변동 가능성이 있는 제공 상태 |
| Session | Hosted 실행의 지속 상태·컴퓨트 단위; 비용과 정리 대상 |

단어가 익숙하지 않아도 괜찮습니다. [A 경로](../paths.md)는 브라우저에서 실제 결과를
본 뒤 필요한 개념을 하나씩 붙이도록 구성했습니다.
