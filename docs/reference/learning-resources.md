This workshop prepares the agentic-app parts of current Microsoft Foundry learning, not every AI certification topic.

## Workshop-to-AI-103 map

| Workshop coverage | Labs/modules | AI-103 skill area | AI-103 weight |
|---|---|---|---|
| Project setup, model choices, roles, quota/cost boundaries, evidence, cleanup | Labs 00–02, 09, 11; owner setup | Plan and manage an Azure AI solution | 25–30% |
| Prompt Agents, MAF agents/tools/MCP, workflows, Hosted agents, evaluation, tracing and operations | Labs 03–05, 07–09; C modules | Implement generative AI and agentic solutions | 30–35% |
| Structured JSON answers from generative prompting (partial); speech not covered | Labs 02, 07 | Implement text analysis solutions | 10–15% |
| Retrieval and grounding with Search and Foundry IQ (partial); Content Understanding extraction is design-only | Lab 06; [specialist scope](../labs/extensions/specialist-scope.md) | Implement information extraction solutions | 10–15% |
| Not covered here | See specialist scope | Implement computer vision solutions | 10–15% |

Computer vision, speech and Content Understanding service execution are not covered in this edition.
See [specialist scope](../labs/extensions/specialist-scope.md) for design-only boundaries.

[AI-102](https://learn.microsoft.com/credentials/certifications/resources/study-guides/ai-102) retired on 2026-06-30.
It was replaced on 2026-06-19 by AI-103, the exam for the Azure AI Apps and Agents Developer Associate certification
([announcement](https://learn.microsoft.com/partner-center/announcements/2026-june)). Skill weights above are from the AI-103 study guide (skills measured as of 2026-04-16).
